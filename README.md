# 🐉 D&DSidian

Добро пожаловать в D&DSidian - это комплексный ресурс, объединяющий все правила, инструменты и материалы для настольной ролевой игры "Dungeons & Dragons" 5-й редакции в одном месте.

## 🧙 О проекте

D&DSidian - это документированная база знаний и интерактивный справочник, созданный для:

- Новых игроков - разобраться в основных правилах и механиках D&D
- Опытных мастеров - быстро найти нужную информацию во время сессии
- Групп игроков - иметь единый источник истины для вашего игрового компендиума

## 🚀 Быстрый старт

1. Перейдите на [Введение](https://zeizel.github.io/dndsidian/docs/intro) - там объяснены базовые концепции
2. Изучите [Правила](/docs/rules) для понимания игровых механик
3. Начните первую сессию с друзьями!

[Начать приключение →](/docs/intro)

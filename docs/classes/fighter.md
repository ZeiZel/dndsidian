# Воин (Fighter)

Человек в полных латах держит строй, прикрывая щитом союзников. Эльфийка выпускает стрелу за стрелой с невероятной точностью, поражая врагов до того, как они приблизятся.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d10 |
| **Основные характеристики** | Сила или Ловкость |
| **Спасброски** | Сила, Телосложение |
| **Владение доспехами** | Все доспехи, щиты |
| **Владение оружием** | Простое, воинское |
| **Роль** | Урон / Защитник |

## Ключевые особенности

### Боевой стиль (Fighting Style)
На 1-м уровне выбираете специализацию:
- **Оборона** — +1 КД в доспехах
- **Дуэлянт** — +2 урона с одноручным оружием
- **Бой большим оружием** — перебрасываете 1-2 на урон
- **Защита** — реакция: помеха атаке против союзника
- **Стрельба** — +2 к атакам дальнобойным оружием
- **Бой двумя оружиями** — добавляете модификатор к урону второй рукой

### Второе дыхание (Second Wind)
Бонусным действием восстанавливаете 1d10 + уровень воина хитов. Восстанавливается на коротком отдыхе.

### Всплеск действий (Action Surge)
С 2-го уровня получаете дополнительное действие раз между отдыхами. На 17-м уровне — дважды.

### Дополнительные атаки
- **5-й уровень** — 2 атаки
- **11-й уровень** — 3 атаки
- **20-й уровень** — 4 атаки

### Несгибаемость (Indomitable)
С 9-го уровня можете перебросить проваленный спасбросок.

## Подклассы (Архетипы)

### Чемпион (Champion)
Простой и эффективный: улучшенные критические удары и атлетизм.

### Мастер боевых искусств (Battle Master)
Боевые приёмы с кубиками превосходства: обезоруживание, выпады, парирование.

### Мистический рыцарь (Eldritch Knight)
Магия + сталь: заклинания школ преграждения и воплощения.

### Эхо-рыцарь (Echo Knight)
Создание теневого эха себя для атак и телепортации.

### Псионический воин (Psi Warrior)
Телекинез и психические удары.

### Рунный рыцарь (Rune Knight)
Гигантские руны для усиления и контроля.

### Самурай (Samurai)
Решительность даёт преимущество и временные хиты.

### Пурпурный рыцарь дракона (Purple Dragon Knight)
Командир: ваши способности помогают союзникам.

## Боевые приёмы (Мастер боевых искусств)

### Атакующие
- **Точный удар** — добавьте кубик к броску атаки
- **Сбивающая атака** — урон + сбить с ног
- **Устрашающая атака** — урон + испуг

### Защитные
- **Парирование** — уменьшить урон реакцией
- **Ответный удар** — контратака после промаха врага
- **Уклонение** — добавить кубик к КД

### Тактические
- **Командирский удар** — союзник атакует реакцией
- **Толкающая атака** — отбросить врага
- **Обезоруживание** — выбить оружие

## Рекомендации по игре

### Распределение характеристик (Сила)
1. **Сила** — для атак в ближнем бою
2. **Телосложение** — для хитов
3. **Ловкость** — при лёгких доспехах

### Распределение характеристик (Ловкость)
1. **Ловкость** — для стрельбы или фехтования
2. **Телосложение** — для хитов
3. **Мудрость** — для спасбросков

### Стиль игры
- Используйте Второе дыхание до полного исцеления
- Сохраняйте Всплеск действий для решающих моментов
- Не забывайте о боевых приёмах
- Воин — гибкий класс: стройте под стиль игры

### Мультиклассирование
Хорошо сочетается с:
- **Плут** — Скрытая атака + Действие
- **Варвар** — ярость + атаки
- **Колдун** — Гексовый клинок
- **Паладин** — божественная кара + атаки

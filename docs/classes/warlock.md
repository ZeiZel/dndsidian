# Колдун (Warlock)

Тифлинг заключает сделку с демоном, получая тёмную силу. Человек служит архифее, его глаза мерцают потусторонним светом.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d8 |
| **Основные характеристики** | Харизма |
| **Спасброски** | Мудрость, Харизма |
| **Владение доспехами** | Лёгкие |
| **Владение оружием** | Простое |
| **Роль** | Урон / Контроль |

## Ключевые особенности

### Потусторонний покровитель (Otherworldly Patron)
На 1-м уровне заключаете договор, определяющий вашу силу и способности.

### Магия договора (Pact Magic)
Уникальная система магии:
- Мало ячеек (максимум 4), но высокого уровня
- **Восстанавливаются на коротком отдыхе**
- Все ячейки одного уровня

| Уровень колдуна | Ячейки | Уровень ячеек |
|-----------------|--------|---------------|
| 1 | 1 | 1-й |
| 2 | 2 | 1-й |
| 3-4 | 2 | 2-й |
| 5-6 | 2 | 3-й |
| 7-8 | 2 | 4-й |
| 9-10 | 2 | 5-й |
| 11-16 | 3 | 5-й |
| 17+ | 4 | 5-й |

### Воззвания (Invocations)
С 2-го уровня выбираете особые способности от покровителя. Меняются при повышении уровня.

### Дар договора (Pact Boon)
На 3-м уровне выбираете форму связи с покровителем:
- **Договор Гримуара** — книга заклинаний, ритуалы
- **Договор Клинка** — магическое оружие
- **Договор Цепи** — особый фамильяр
- **Договор Талисмана** — амулет с бонусами

### Мистический арканум (Mystic Arcanum)
С 11-го уровня получаете заклинания 6-9 уровня, используемые раз в день без ячеек.

## Подклассы (Покровители)

### Архифея (The Archfey)
Фейская магия: очарование, страх, телепортация.

### Исчадие (The Fiend)
Демоническая сила: огонь, временные хиты, удача.

### Великий Древний (The Great Old One)
Космический ужас: телепатия, страх, психический урон.

### Небожитель (The Celestine)
Небесная сила: исцеление, сияющий урон.

### Гексовый Клинок (The Hexblade)
Боевой колдун: атаки Харизмой, проклятья, критические удары.

### Фатом (The Fathomless)
Морская глубина: щупальца, дыхание под водой.

### Нежить (The Undead)
Некротическая сила: форма ужаса, нежить-слуга.

### Джинн (The Genie)
Элементальный покровитель: сосуд-убежище, элементальный урон.

## Воззвания (избранные)

### Для всех
- **Мистическое зрение** — видите магию по желанию
- **Дьявольское зрение** — видите в магической тьме 120 фт
- **Маска множества ликов** — Маскировка по желанию
- **Голос Хозяина Цепи** — говорите через фамильяра

### Для Мистического заряда (Eldritch Blast)
- **Агонизирующий заряд** — +Харизма к урону
- **Отталкивающий заряд** — отбросить цель на 10 фт
- **Копьё (250 фт)** — увеличенная дальность

### Для Договора Клинка
- **Жажда клинка** — дополнительная атака
- **Улучшенное оружие договора** — +1/+2/+3

### Для Договора Гримуара
- **Книга древних секретов** — ритуалы из любых списков
- **Аспект луны** — не нужен сон

## Заклинания (избранные)

### Заговоры
- **Мистический заряд** — лучшая атака колдуна, растёт с уровнем
- **Создание костра** — урон в области

### 1-й уровень
- **Ведьмин снаряд** — +1d6 урона по отмеченной цели
- **Доспехи Агатиса** — временные хиты + урон атакующим
- **Порча** — помеха на атаки и проверки

### 2-й уровень
- **Удержание личности** — паралич
- **Невидимость** — скрытность
- **Корона безумия** — контроль врага

### 3-й уровень
- **Голод Хадара** — урон + труднопроходимая местность
- **Страх** — AOE контроль
- **Рассеивание магии** — снятие эффектов

## Рекомендации по игре

### Распределение характеристик
1. **Харизма** — для заклинаний и навыков
2. **Телосложение** — для хитов и концентрации
3. **Ловкость** — для КД

### Стиль игры
- Мистический заряд + Агонизирующий заряд = ваш основной урон
- Короткие отдыхи — ваши друзья
- Воззвания — гибкость вне боя
- Концентрация на Ведьмином снаряде

### Сборка Гексового Клинка
1. Харизма для атак и урона
2. Договор Клинка + Жажда клинка
3. Ведьмин снаряд + Проклятие Гексового Клинка
4. Две атаки + бонусный урон

### Мультиклассирование
Хорошо сочетается с:
- **Паладин** — ячейки на коротком отдыхе для кары
- **Чародей** — больше ячеек, метамагия
- **Бард** — больше заклинаний и навыков

# Плут (Rogue)

Полурослик скользит в тень, оставаясь невидимым для стражников. Эльфийка вскрывает замок за считанные секунды, пока её товарищи прикрывают.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d8 |
| **Основные характеристики** | Ловкость |
| **Спасброски** | Ловкость, Интеллект |
| **Владение доспехами** | Лёгкие |
| **Владение оружием** | Простое, арбалеты, длинные мечи, рапиры, короткие мечи |
| **Роль** | Урон / Навыки |

## Ключевые особенности

### Компетентность (Expertise)
Удваиваете бонус мастерства для двух навыков или воровских инструментов. Ещё два на 6-м уровне.

### Скрытая атака (Sneak Attack)
Раз в ход наносите дополнительный урон:
- Требуется: преимущество ИЛИ союзник в 5 футах от цели
- Только оружие с тонкостью или дальнобойное
- Урон растёт: 1d6 (1 ур.) → 10d6 (19 ур.)

### Воровской жаргон (Thieves' Cant)
Тайный язык для общения с другими плутами.

### Хитрое действие (Cunning Action)
С 2-го уровня бонусным действием: Рывок, Отход или Прятание.

### Уклонение (Uncanny Dodge)
С 5-го уровня: реакцией уменьшаете урон от атаки вдвое.

### Уворот (Evasion)
С 7-го уровня: при успешном спасброске Ловкости — 0 урона, при провале — половина.

### Надёжный талант (Reliable Talent)
С 11-го уровня: результат меньше 10 на проверках навыков с владением считается 10.

## Подклассы (Архетипы)

### Вор (Thief)
Классический плут: быстрые руки, использование магических предметов, второй этаж.

### Убийца (Assassin)
Смертельный первый удар: автокритические попадания по застигнутым врасплох, маскировка и яды.

### Мистический ловкач (Arcane Trickster)
Магия + хитрость: заклинания иллюзии и очарования, магическая рука-помощник.

### Инквизитор (Inquisitive)
Детектив: чтение противников, невосприимчивость к обману.

### Мастер-разведчик (Scout)
Выживальщик: бонусные навыки, превосходная мобильность.

### Фантом (Phantom)
Связь со смертью: дополнительный урон, хождение сквозь стены.

### Ловкий стрелок (Soulknife)
Псионические клинки: телепатия и мощные психические атаки.

### Виртуоз клинков (Swashbuckler)
Дуэлянт: Скрытая атака в поединках, элегантный побег.

## Заклинания Мистического ловкача

### Заговоры (3 известно)
- **Волшебная рука** — улучшенная версия с невидимостью
- **Малая иллюзия** — создание отвлекающих образов
- **Сообщение** — тайная связь

### 1-й уровень
- **Очарование личности** — манипуляция
- **Маскировка** — изменение внешности
- **Усыпление** — отключение врагов
- **Невидимость** (позже) — скрытность

## Рекомендации по игре

### Распределение характеристик
1. **Ловкость** — для атак, КД и навыков
2. **Телосложение** — для выживания
3. **Интеллект/Харизма** — для навыков

### Стиль игры
- Каждый ход ищите условия для Скрытой атаки
- Используйте Хитрое действие для позиционирования
- Компетентность в важных навыках делает вас экспертом
- Избегайте прямых столкновений в начале боя

### Тактика Скрытой атаки
1. **Преимущество**: Прячьтесь перед атакой
2. **Союзник рядом**: Атакуйте того, кто в ближнем бою с товарищем
3. **Виртуоз клинков**: Скрытая атака в поединке без преимущества

### Важные навыки
- **Скрытность** — для засад и разведки
- **Ловкость рук** — карманные кражи и фокусы
- **Воровские инструменты** — замки и ловушки
- **Проницательность** — чтение лжи
- **Восприятие** — обнаружение опасности

### Мультиклассирование
Хорошо сочетается с:
- **Воин** — Всплеск действий для двойной Скрытой атаки
- **Следопыт** — навыки выживания
- **Монах** — мобильность
- **Бард** — больше навыков и магии

# Чародей (Sorcerer)

Тифлинг выпускает огонь из ладоней, её глаза пылают силой предков. Полуэльф изменяет заклинание на лету, усиливая его до невообразимой мощи.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d6 |
| **Основные характеристики** | Харизма |
| **Спасброски** | Телосложение, Харизма |
| **Владение доспехами** | Нет |
| **Владение оружием** | Кинжалы, дротики, пращи, посохи, лёгкие арбалеты |
| **Роль** | Урон / Контроль |

## Ключевые особенности

### Использование заклинаний
Чародей — полный заклинатель на Харизме. Знает ограниченное число заклинаний, но не готовит их.

### Чародейское происхождение (Sorcerous Origin)
На 1-м уровне выбираете источник врождённой магии.

### Источник магии (Font of Magic)
С 2-го уровня получаете очки чародейства:
- Преобразование ячеек в очки и обратно
- Использование метамагии

### Метамагия (Metamagic)
С 3-го уровня выбираете способы изменения заклинаний:

| Метамагия | Очки | Эффект |
|-----------|------|--------|
| Усиленное заклинание | 1 | Перебросить кубики урона |
| Продлённое заклинание | 1 | Удвоить длительность (до 24ч) |
| Расширенное заклинание | 1 | Дальность ×2 |
| Усиленное заклинание | 3 | Цель имеет помеху на спасбросок |
| Ускоренное заклинание | 2 | Бонусным действием вместо действия |
| Незаметное заклинание | 1 | Без вербальных/соматических компонентов |
| Раздвоенное заклинание | 1+ | Вторая цель (уровень ячейки +1) |
| Осторожное заклинание | 1 | Союзники автоуспех на спасброске |

## Подклассы (Происхождения)

### Драконья кровь (Draconic Bloodline)
Предок-дракон: усиленный урон элементом, крылья, КД.

### Дикая магия (Wild Magic)
Хаотичная сила: случайные магические эффекты, манипуляция удачей.

### Божественная душа (Divine Soul)
Доступ к заклинаниям жреца: исцеление + чародейство.

### Тёмный (Shadow Magic)
Теневая сила: Тьма, призыв гончей, ходьба в тенях.

### Штормовая магия (Storm Sorcery)
Ветер и молнии: полёт, отталкивание врагов.

### Аберрантный разум (Aberrant Mind)
Псионическая сила: телепатия, изменённые заклинания.

### Часовой (Clockwork Soul)
Порядок Механуса: защита от манипуляций, восстановление ячеек.

## Заклинания (избранные)

### Заговоры
- **Огненный снаряд** — основная атака
- **Луч холода** — урон + замедление
- **Шокирующее касание** — ближний бой + реакции

### 1-й уровень
- **Волшебная стрела** — автопопадание
- **Щит** — +5 КД реакцией
- **Усыпление** — контроль без концентрации

### 2-й уровень
- **Опаляющий луч** — 3 луча по 2d6
- **Невидимость** — скрытность
- **Паутина** — контроль области

### 3-й уровень
- **Огненный шар** — классика AOE
- **Молния** — урон по линии
- **Ускорение** — усиление союзника

## Комбо метамагии

### Ускоренный Огненный шар
- 2 очка чародейства
- Бонусным действием: 8d6 урона по области
- Действие свободно для другого заклинания

### Усиленное Опаляющее касание
- 3 очка чародейства
- Помеха на спасбросок
- Парализованная цель не устоит

### Раздвоенное Ускорение
- 4 очка чародейства
- Два союзника ускорены
- Огромный буст команде

### Незаметный Приказ
- 1 очко чародейства
- Без слов и жестов
- Социальная магия инкогнито

## Рекомендации по игре

### Распределение характеристик
1. **Харизма** — для заклинаний
2. **Телосложение** — для хитов и концентрации
3. **Ловкость** — для КД

### Стиль игры
- Выбирайте заклинания тщательно — замена ограничена
- Метамагия — ваше преимущество перед волшебниками
- Экономьте очки чародейства для важных моментов
- Концентрация на мощных заклинаниях

### Выбор метамагии
**Обязательные:**
- Ускоренное заклинание — гибкость в бою
- Раздвоенное заклинание — эффективность

**Рекомендуемые:**
- Усиленное — для контрольных заклинаний
- Осторожное — для AOE рядом с союзниками

### Мультиклассирование
Хорошо сочетается с:
- **Паладин** — ячейки для Божественной кары
- **Колдун** — больше ячеек, Eldrich Blast
- **Бард** — больше заклинаний Харизмы

# Следопыт (Ranger)

Эльфийка скользит между деревьями, выслеживая орков. Человек с двумя мечами вступает в бой с троллем, зная каждую его слабость.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d10 |
| **Основные характеристики** | Ловкость, Мудрость |
| **Спасброски** | Сила, Ловкость |
| **Владение доспехами** | Лёгкие, средние, щиты |
| **Владение оружием** | Простое, воинское |
| **Роль** | Урон / Разведка |

## Ключевые особенности

### Избранный враг (Favored Enemy)
Преимущество на проверки для выслеживания и вспоминания информации о выбранном типе существ.

### Природный исследователь (Natural Explorer)
В избранной местности: двойной бонус мастерства к связанным проверкам, игнорирование труднопроходимой местности, не теряетесь.

### Боевой стиль (Fighting Style)
На 2-м уровне: Стрельба, Дуэлянт, Оборона или Бой двумя оружиями.

### Использование заклинаний
С 2-го уровня: полузаклинатель на Мудрости.

### Первобытная осведомлённость (Primeval Awareness)
Чувствуете присутствие некоторых типов существ в пределах 1 мили (6 миль в избранной местности).

### Дополнительная атака (Extra Attack)
С 5-го уровня — две атаки за действие.

### Исчезновение (Vanish)
С 14-го уровня можете прятаться бонусным действием; не можете быть выслежены немагически.

## Подклассы (Архетипы)

### Охотник (Hunter)
Классический следопыт: выбор специализации против разных типов угроз.

### Повелитель зверей (Beast Master)
Верный звериный компаньон сражается рядом.

### Сумеречный охотник (Gloom Stalker)
Мастер темноты: невидимость во мраке и мощный первый раунд.

### Странник горизонта (Horizon Walker)
Защитник планарных границ: телепортация и силовой урон.

### Убийца монстров (Monster Slayer)
Охотник на сверхъестественное: анализ врагов и защита от магии.

### Рой Фейри (Fey Wanderer)
Фейская магия: очарование и психический урон.

### Хранитель роя (Swarmkeeper)
Контроль над роем существ для урона и передвижения.

### Собиратель скверны (Drakewarden)
Компаньон-дракончик, растущий с уровнем.

## Заклинания (избранные)

### 1-й уровень
- **Охотничья метка** — +1d6 урона по отмеченной цели
- **Добрая ягода** — 10 ягод, каждая лечит 1 хит
- **Опутывание** — контроль области
- **Лечение ран** — исцеление

### 2-й уровень
- **Шипы** — ловушка на местности
- **Бесшумное сообщение** — тайная связь
- **Найти ловушки** — обнаружение опасностей
- **Пропуск без следа** — скрытность для группы

### 3-й уровень
- **Призыв животных** — призыв зверей
- **Молния** — урон по линии

## Рекомендации по игре

### Распределение характеристик
1. **Ловкость** — для атак и КД
2. **Мудрость** — для заклинаний
3. **Телосложение** — для хитов

### Стиль игры
- Используйте Охотничью метку постоянно
- Ведите разведку для группы
- Комбинируйте дальний бой с контролем
- Помните о преимуществах в избранной местности

### Выбор архетипа

**Охотник** — если хотите больше урона и гибкости:
- Колосс-убийца (d8 урона крупным)
- Мультиатака (по группам врагов)

**Повелитель зверей** — если хотите компаньона:
- Зверь получает действие при вашей команде
- Лучше работает с TCoE исправлениями

**Сумеречный охотник** — для максимальной эффективности:
- Дополнительная атака и урон в первом раунде
- Невидимость в темноте

### Мультиклассирование
Хорошо сочетается с:
- **Плут** — Скрытая атака + навыки
- **Друид** — больше заклинаний природы
- **Воин** — Всплеск действий

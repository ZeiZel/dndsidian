# Волшебник (Wizard)

Старый человек листает древний гримуар, готовя разрушительное заклинание. Гном чертит руны защиты, создавая магический барьер.

## Обзор класса

| Параметр | Значение |
|----------|----------|
| **Кость хитов** | d6 |
| **Основные характеристики** | Интеллект |
| **Спасброски** | Интеллект, Мудрость |
| **Владение доспехами** | Нет |
| **Владение оружием** | Кинжалы, дротики, пращи, посохи, лёгкие арбалеты |
| **Роль** | Контроль / Урон |

## Ключевые особенности

### Использование заклинаний
Волшебник — полный заклинатель на Интеллекте с самым большим списком заклинаний в игре.

### Книга заклинаний (Spellbook)
Ваш главный инструмент:
- Начинаете с 6 заклинаниями 1-го уровня
- +2 заклинания на каждом уровне
- Можете копировать заклинания из свитков и книг других волшебников
- Стоимость копирования: 2 часа и 50 зм за уровень заклинания

### Подготовка заклинаний
Каждый день готовите заклинания из книги:
- Количество = Интеллект + уровень волшебника
- Можете менять набор после длинного отдыха

### Восстановление арканы (Arcane Recovery)
Раз в день на коротком отдыхе восстанавливаете ячейки заклинаний:
- Суммарный уровень ячеек ≤ половина уровня волшебника (округление вверх)
- Нельзя восстанавливать ячейки 6+ уровня

### Арканная традиция (Arcane Tradition)
На 2-м уровне выбираете школу магии для специализации.

## Подклассы (Школы магии)

### Школа преграждения (Abjuration)
Защитная магия: Арканный щит поглощает урон.

### Школа воплощения (Evocation)
Боевая магия: Изваянные заклинания не вредят союзникам, Усиленное воплощение.

### Школа прорицания (Divination)
Предвидение: Знамения позволяют заменить броски кубика.

### Школа очарования (Enchantment)
Контроль разума: Гипнотический взгляд, Раздвоенное очарование.

### Школа иллюзии (Illusion)
Обман чувств: Улучшенные иллюзии становятся реальностью.

### Школа некромантии (Necromancy)
Власть над смертью: Создание нежити, вытягивание жизни.

### Школа превращения (Transmutation)
Изменение материи: Философский камень, трансмутация.

### Школа вызова (Conjuration)
Призыв: Малый вызов, усиленные призванные существа.

### Хрономант (Chronurgy Magic)
Манипуляции временем: замедление врагов, сохранение заклинаний.

### Гравитург (Graviturgy Magic)
Манипуляции гравитацией: изменение веса, притяжение.

### Боевая магия (War Magic)
Защита + урон: Арканное отклонение, тактическое колдовство.

### Порядок писцов (Order of Scribes)
Магическая книга-компаньон: изменение типа урона, мгновенные ритуалы.

## Заклинания (избранные)

### Заговоры
- **Огненный снаряд** — основная атака
- **Свет** — освещение
- **Волшебная рука** — манипуляции
- **Малая иллюзия** — отвлечение

### 1-й уровень (обязательные)
- **Щит** — +5 КД реакцией
- **Волшебная стрела** — автопопадание
- **Обнаружение магии** (ритуал) — анализ магии
- **Найти фамильяра** (ритуал) — помощник

### 2-й уровень
- **Невидимость** — скрытность
- **Паутина** — контроль области
- **Мерцание** — бонус КД + тактика

### 3-й уровень
- **Огненный шар** — классический AOE
- **Противозаклятие** — отмена вражеских заклинаний
- **Рассеивание магии** — снятие эффектов
- **Ускорение** — усиление союзника

### Высокие уровни
- **Полиморф** (4) — трансформация
- **Стена силы** (5) — непробиваемый барьер
- **Дезинтеграция** (6) — массивный урон
- **Силовая клетка** (7) — ловушка
- **Остановка времени** (9) — несколько раундов действий

## Рекомендации по игре

### Распределение характеристик
1. **Интеллект** — для заклинаний
2. **Телосложение** — для хитов и концентрации
3. **Ловкость** — для КД

### Стиль игры
- Собирайте свитки и книги заклинаний
- Готовьте заклинания под ситуацию
- Держите Щит и Противозаклятие готовыми
- Контролируйте поле боя, а не бросайтесь в бой

### Тактика
1. Контроль области (Паутина, Огненный шар)
2. Усиление союзников (Ускорение)
3. Защита себя (Щит, Мерцание)
4. Нейтрализация угроз (Удержание, Полиморф)

### Важные ритуалы
- **Найти фамильяра** — разведка, помощь
- **Обнаружение магии** — анализ
- **Понимание языков** — перевод
- **Леомундова хижина** — безопасный отдых
- **Фантомный скакун** — транспорт

### Мультиклассирование
Хорошо сочетается с:
- **Воин** — для боевого мага
- **Жрец (1 ур.)** — тяжёлые доспехи
- **Изобретатель** — средние доспехи + щит

# Классы D&D 5e

Класс определяет основные способности вашего персонажа, его стиль боя и роль в команде. В D&D 5e доступно 13 классов, каждый с уникальной механикой и множеством подклассов.

## Выбор класса

При выборе класса учитывайте:
- **Роль в команде** — защитник, урон, поддержка или контроль
- **Основные характеристики** — какие атрибуты будут главными
- **Сложность освоения** — некоторые классы требуют больше опыта
- **Стиль игры** — ближний/дальний бой, магия, хитрость

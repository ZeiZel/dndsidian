# Расы D&D 5e

Раса определяет происхождение вашего персонажа, его физические особенности и врождённые способности. В D&D 5e доступно множество рас, каждая с уникальными чертами.

## Выбор расы

При выборе расы учитывайте:
- **Бонусы характеристик** — какие атрибуты усиливаются
- **Расовые особенности** — уникальные способности
- **Размер и скорость** — влияют на игровую механику
- **Ролевые аспекты** — культура и история

## Разновидности (подрасы)

Многие расы имеют подрасы с дополнительными бонусами:

### Эльфы
- **Высший эльф** — дополнительный заговор, +1 Интеллект
- **Лесной эльф** — скорость 35 фт, Маска дикой природы, +1 Мудрость
- **Тёмный эльф (Дроу)** — улучшенное тёмное зрение, магия дроу, +1 Харизма

### Дварфы
- **Горный дварф** — владение доспехами, +2 Сила
- **Холмовой дварф** — +1 Мудрость, +1 хит за уровень

### Полурослики
- **Легконогий** — скрытность за союзниками, +1 Харизма
- **Коренастый** — сопротивление яду, +1 Телосложение

### Гномы
- **Лесной гном** — Малая иллюзия, общение с животными
- **Скальный гном** — знание механизмов, изобретатель

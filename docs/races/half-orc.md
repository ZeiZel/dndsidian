# Полуорк (Half-Orc)

Полуорки несут в себе силу и свирепость своих оркских предков. Их физическая мощь и стойкость делают их грозными воинами.

## Обзор расы

| Параметр | Значение |
|----------|----------|
| **Размер** | Средний |
| **Скорость** | 30 футов |
| **Языки** | Общий, Орочий |
| **Источник** | Player's Handbook |

## Бонусы характеристик

**+2 Сила, +1 Телосложение**

Идеально для бойцов ближнего боя.

## Особенности расы

### Тёмное зрение
Видите в темноте на 60 футов.

### Угрожающий
Владение навыком Запугивание.

### Неукротимая стойкость
Когда хиты падают до 0, но вы не убиты, можете остаться с 1 хитом. Раз в длинный отдых.

### Дикие атаки
При критическом попадании оружием ближнего боя бросаете один дополнительный кубик урона.

## Неукротимая стойкость — анализ

Одна из лучших защитных способностей:
- Спасает от смерти раз в день
- Работает автоматически
- Позволяет продолжить бой или отступить

## Дикие атаки — анализ

Увеличивает урон критических попаданий:
- d12 топор → 3d12 вместо 2d12
- Отлично с оружием большого урона
- Сочетается с Жестоким критическим ударом варвара

## Сочетания с классами

| Класс | Почему хорошо |
|-------|---------------|
| Варвар | Сила + Телосложение, Дикие атаки + Жестокий крит |
| Воин | Сила, выживаемость |
| Паладин | Сила, Стойкость для последней кары |
| Плут (Громила) | Сила + Запугивание |

## Культура

### Между двух миров
Полуорки часто отвергаются обоими обществами.

### Сила
В орочьей культуре сила — высшая ценность, и полуорки это наследуют.

### Самоутверждение
Многие стремятся доказать свою ценность делами.

## Свойства оружия

| Свойство | Описание |
|----------|----------|
| **Лёгкое** | Можно использовать для боя двумя оружиями |
| **Тяжёлое** | Маленькие существа атакуют с помехой |
| **Тонкое** | Можно использовать Ловкость вместо Силы |
| **Универсальное** | Одной или двумя руками (больший урон) |
| **Двуручное** | Требует две руки |
| **Досягаемость** | Атака на 10 футов вместо 5 |
| **Метательное** | Можно метать для дальней атаки |
| **Боеприпасы** | Требуются стрелы/болты |
| **Перезарядка** | Только одна атака за действие |

# Черты (Feats) в D&D 5e

## Что такое черты?

Черты (Feats) - опциональные способности, которые можно взять вместо улучшения характеристик (ASI).

Когда доступны:  
На уровнях 4, 8, 12, 16, 19 (когда класс даёт ASI)

Выбор:  
Либо +2 к одной характеристике (или +1 к двум), либо одна черта.

:::caution Важно
Черты - опциональное правило. Спроси у мастера!
:::

## 🎯 Популярные черты по категориям

### ⚔️ Боевые черты

Great Weapon Master

- Требования: -
- Эффект:
  - При критическом попадании или убийстве: бонусная атака
  - Можешь взять -5 к попаданию за +10 к урону
- Для кого: Воины с двуручным оружием

Sharpshooter

- Требования: -
- Эффект:
  - Игнорируй полуукрытие/3/4 укрытие
  - Дальние атаки без помехи на максимальной дистанции
  - Можешь взять -5 к попаданию за +10 к урону
- Для кого: Лучники, стрелки

Polearm Master

- Требования: -
- Эффект:
  - Бонусная атака древком (1d4)
  - Атака по возможности, когда враг входит в досягаемость
- Для кого: Воины с копьями/глефами/алебардами

Crossbow Expert

- Требования: -
- Эффект:
  - Игнорируй помеху в ближнем бою с арбалетами
  - Бонусная атака ручным арбалетом
  - Можешь стрелять после атаки Action
- Для кого: Арбалетчики

### 🛡️ Защитные черты

Tough

- Требования: -
- Эффект: +2 максимума хитов за уровень (ретроактивно)
- Для кого: Танки, хрупкие классы

Resilient

- Требования: -
- Эффект:
  - +1 к выбранной характеристике
  - Владение спасброском этой характеристики
- Для кого: Заклинатели (обычно берут ТЕЛ для концентрации)

Lucky

- Требования: -
- Эффект: 3 "очка удачи" (переброс любого d20) в день
- Для кого: Все!

Shield Master

- Требования: -
- Эффект:
  - Бонусным действием толкнуть врага щитом
  - +2 к спасброскам ЛОВ от заклинаний при щите
  - Укрыться за щитом (no damage при успешном спасброске)
- Для кого: Танки с щитами

### 🔮 Магические черты

War Caster

- Требования: Умение колдовать
- Эффект:
  - Преимущество на концентрацию при уроне
  - Можешь колдовать с руками, занятыми оружием/щитом
  - Можешь использовать заклинание вместо атаки по возможности
- Для кого: Заклинатели в ближнем бою (Паладин, Жрец, Друид)

Spell Sniper

- Требования: Умение колдовать
- Эффект:
  - ×2 дальность заклинаний с атакой
  - Игнорируй укрытие для заклинаний
  - +1 заговор с атакой
- Для кого: Колдуны, Чародеи с Eldritch Blast

Elemental Adept

- Требования: Умение колдовать
- Эффект:
  - Игнорируй сопротивление выбранного типа урона
  - 1 на кости урона считается как 2
- Для кого: Заклинатели, специализирующиеся на одном элементе

Ritual Caster

- Требования: ИНТ/МДР 13+
- Эффект: Получаешь ритуальную книгу с 2 ритуалами, можешь добавлять новые
- Для кого: Не-заклинатели для утилитарности

### 🏃 Утилитарные черты

Alert

- Требования: -
- Эффект:
  - +5 к инициативе
  - Не можешь быть застигнут врасплох
  - Невидимые враги не получают преимущество
- Для кого: Все (особенно плуты, стрелки)

Mobile

- Требования: -
- Эффект:
  - +10 фт скорости
  - После атаки по врагу он не может совершить атаку по возможности
  - Игнорируй труднопроходимую местность при рывке
- Для кого: Плуты, мобильные бойцы

Observant

- Требования: -
- Эффект:
  - +1 к ИНТ или МДР
  - +5 к пассивному Восприятию и Расследованию
  - Можешь читать по губам
- Для кого: Следопыты, детективы

Sentinel

- Требования: -
- Эффект:
  - Атака по возможности даже при Disengage
  - Попадание атакой по возможности обнуляет скорость врага
  - Можешь атаковать врагов, атакующих союзников
- Для кого: Танки, защитники

### 🎭 Ролевые черты

Actor

- Требования: -
- Эффект:
  - +1 к ХАР
  - Преимущество на обман/выступление для имитации
  - Можешь имитировать голоса
- Для кого: Актёры, шпионы, барды

Linguist

- Требования: -
- Эффект:
  - +1 к ИНТ
  - +3 языка
  - Можешь создавать шифры
- Для кого: Дипломаты, учёные

Keen Mind

- Требования: -
- Эффект:
  - +1 к ИНТ
  - Всегда знаешь направление севера
  - Помнишь детали последнего месяца
- Для кого: Навигаторы, мозги группы

## 🤔 ASI или черта?

### Бери ASI, если:

✅ Твоя главная характеристика ниже 18  
✅ Ты новичок (проще играть)  
✅ Ты зависишь от одной характеристики сильно

### Бери черту, если:

✅ Твоя главная характеристика 18+  
✅ Черта даёт огромный буст (GWM, Sharpshooter)  
✅ Черта критична для билда (Polearm Master + Sentinel комбо)

### Половинные черты

Некоторые черты дают +1 к характеристике - best of both worlds!

Примеры:

- Resilient (+1 к любой характеристике)
- Actor (+1 ХАР)
- Observant (+1 ИНТ/МДР)
- Linguist (+1 ИНТ)

Хороший выбор при нечётной характеристике (13, 15, 17).

## 🚫 Переоцененные черты

Weapon Master - почти бесполезна. Лучше мультикласс.

Grappler - ограниченная. Можно грэпплить и без черты.

Dual Wielder - слабая. Бой двумя оружиями не очень силён в 5e.

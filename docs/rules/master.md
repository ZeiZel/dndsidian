# Полное руководство для Мастера D&D 5e

## 1. Создание столкновений (баланс CR)

### Что такое CR (Challenge Rating)?

CR (Рейтинг сложности) - показатель опасности монстра:

- CR 1/8 = вызов для группы из 4 персонажей 1 уровня (лёгкий)
- CR 1 = вызов средней сложности для 4 персонажей 1 уровня
- CR 5 = смертельная угроза для 4 персонажей 1 уровня ИЛИ средний вызов для 4 персонажей 5 уровня

### Бюджет опыта (XP Budget)

Шаг 1: Определи порог сложности

Для группы из 4 персонажей определённого уровня есть пороги XP:

|Уровень|Лёгкий|Средний|Сложный|Смертельный|
|---|---|---|---|---|
|1|100|200|300|400|
|2|200|400|600|800|
|3|300|600|900|1400|
|4|500|1000|1500|2200|
|5|600|1200|1800|2800|

_(Для других уровней см. DMG стр. 82)_

Шаг 2: Выбери монстров

Каждый монстр имеет XP стоимость по CR:

|CR|XP|Примеры|
|---|---|---|
|0|10|Крыса, обычный краб|
|1/8|25|Бандит, гигантская крыса|
|1/4|50|Гоблин, скелет|
|1/2|100|Орк, чёрный медведь|
|1|200|Гуль, дайр-волк|
|2|450|Огр, грифон|
|3|700|Мантикора, рыцарь|
|4|1100|Чёрный пудинг, оборотень|
|5|1800|Воздушный элементаль, гладиатор|

Шаг 3: Примени множитель за количество врагов

Чем больше врагов, тем опаснее (эффект действий):

|Количество врагов|Множитель XP|
|---|---|
|1|×1|
|2|×1.5|
|3-6|×2|
|7-10|×2.5|
|11-14|×3|
|15+|×4|

ВАЖНО: Множитель применяется только для определения сложности, НЕ для награды XP.

### Пример расчёта столкновения

Задача: Создать средней сложности бой для 4 персонажей 3 уровня.

Шаг 1: Порог для среднего боя = 600 XP × 4 = 2400 XP

Шаг 2: Выбираю врагов:

- 4 гоблина (CR 1/4, по 50 XP) = 200 XP
- 1 хобгоблин (CR 1/2, 100 XP) = 100 XP
- Базовый XP: 200 + 100 = 300 XP

Шаг 3: Множитель за количество (5 врагов = ×2):

- Эффективный XP: 300 × 2 = 600 XP

Вердикт: Это будет лёгкое столкновение (600 < 2400). Нужно усилить.

Корректировка: Добавлю ещё 2 хобгоблинов:

- 4 гоблина (200 XP) + 3 хобгоблина (300 XP) = 500 XP базовых
- 7 врагов = множитель ×2.5
- Эффективный XP: 500 × 2.5 = 1250 XP

Вердикт: Теперь это средней сложности бой (1250 примерно половина от 2400).

### Быстрые правила баланса

Правило 1: Один монстр = скучно

- Лучше 3-6 врагов разного типа, чем 1 большой монстр
- Исключение: драматичные босс-файты

Правило 2: Действия решают

- Если врагов больше, чем игроков - они получают больше ходов = опаснее
- Используй легендарные действия для боссов (3 действия между ходами игроков)

Правило 3: Окружение имеет значение

- Враги на возвышении, за укрытием, с ловушками = эффективно +1-2 CR

Правило 4: Ресурсы партии

- Первый бой дня = партия на пике (все заклинания/способности)
- 6-8 столкновений = партия истощена
- Калибруй сложность под это

### Смертельные бои (когда использовать)

Смертельный ≠ ТПК (Total Party Kill)

- Смертельный = высокий шанс, что кто-то упадёт до 0 хитов
- Используй для:
    - Кульминационных моментов
    - Боссов
    - Драматических сцен
- НЕ используй как "случайную встречу"

## 2. Сложность проверок (когда требовать броски)

### Базовое правило

Требуй бросок только если:

1. Исход неопределён
2. Есть последствия провала
3. Действие значимо для сюжета

НЕ требуй бросок если:

- Задача тривиальна для персонажа (вор с Ловкостью рук +7 открывает обычный замок - автоуспех)
- Невозможно (даже критический успех не поможет)
- Нет давления времени/опасности

### Таблица сложности (DC)

|DC|Сложность|Когда использовать|Пример|
|---|---|---|---|
|5|Очень легко|Рутина под давлением|Вспомнить общеизвестный факт в бою|
|10|Легко|Обычная задача|Успокоить обычную лошадь|
|15|Средне|Стандартный вызов|Убедить стражника пропустить без документов|
|20|Сложно|Опытные могут справиться|Выследить невидимого врага|
|25|Очень сложно|Только мастера|Вспомнить забытое древнее заклинание|
|30|Почти невозможно|Легендарные герои|Убедить дракона отдать сокровище|

### Ситуационные модификаторы DC

|Ситуация|Модификатор|
|---|---|
|У персонажа есть нужные инструменты|-2 DC|
|Действует в знакомой обстановке|-2 DC|
|Есть помощь от союзника|Преимущество (не снижение DC)|
|Плохие условия (темнота, шум, спешка)|+2-5 DC|
|Крайне неблагоприятные условия|Помеха|

### Групповые проверки

Когда использовать:

- Партия лезет по скале
- Все пытаются быть незаметными
- Коллективный поиск

Правило:

- Больше половины группы успешно = вся группа успешна

Пример:

- 4 игрока делают Скрытность
- Результаты: 18, 14, 12, 8
- 3 из 4 успешны → вся группа проходит незамеченной
- Персонаж с 8 получает помощь от успешных

### Пассивные проверки

Пассивная проверка = 10 + модификатор

Когда использовать:

- Восприятие (замечают ли засаду)
- Проницательность (чувствуют ли обман)
- Расследование (замечают ли улику без активного поиска)

Пример:

- Вор с Восприятием +5 имеет пассивное Восприятие 15
- Ловушка требует DC 14 для обнаружения
- Вор автоматически замечает её, проходя мимо

### Частые ошибки Мастеров

❌ Ошибка 1: Требовать бросок на всё

- "Открываешь дверь" - НЕ требует броска
- "Идёшь по ровной дороге" - НЕ требует броска

✅ Правильно: Броски только для значимых действий

❌ Ошибка 2: Один DC для всех ситуаций

- Убедить враждебного орка ≠ убедить дружелюбного торговца

✅ Правильно: Калибруй DC под контекст

❌ Ошибка 3: Игнорировать критические успехи/провалы на проверках

- В D&D 5e критические успехи/провалы работают ТОЛЬКО для атак, НЕ для проверок
- Натуральная 20 на Убеждении не заставит дракона отдать сокровище

✅ Правильно: 20 = просто высокий результат, не автоуспех

## 3. Импровизация правил

### Золотое правило

"Скажи Да, или скажи Да, но..."

- Игрок: "Могу ли я спрыгнуть с балкона, схватиться за люстру и ударить орка ногами?"
- ❌ Плохо: "Нет, это не в правилах"
- ✅ Хорошо: "Да! Сделай проверку Акробатики (DC 15). При успехе - атака с преимуществом, при провале - падаешь и получаешь урон"

### Импровизация урона

Если нет чёткого правила, используй эту таблицу:

|Уровень персонажей|Лёгкий урон|Средний урон|Тяжёлый урон|
|---|---|---|---|
|1-4|1d6 (3)|2d6 (7)|4d6 (14)|
|5-10|2d6 (7)|4d6 (14)|8d6 (28)|
|11-16|4d6 (14)|8d6 (28)|12d6 (42)|
|17-20|8d6 (28)|12d6 (42)|20d6 (70)|

Примеры:

- Игрок прыгает в костёр (1-4 уровень): 2d6 урона огнём (средний)
- Игрок падает со скалы 30 футов (11 уровень): 4d6 урона (лёгкий для их уровня, но по правилам падение = 1d6 за 10 футов = 3d6)

### Импровизация DC для нестандартных действий

Формула:

`DC = 10 + сложность задачи + ситуационные факторы`

Пример:

- Игрок хочет прыгнуть с лошади на движущуюся телегу
- Базовая сложность: +5 (акробатическое действие)
- Телега движется: +2
- Дождь: +2
- Итого DC 19

### Правило "Cool Rule"

Если игрок придумал крутую идею - позволь с небольшим штрафом

Пример:

- Игрок: "Могу ли я выстрелить в верёвку, на которой висит люстра, чтобы она упала на врагов?"
- Мастер: "Да! Сделай атаку по верёвке (AC 15, малая цель). При попадании - враги делают спасбросок ЛОВ DC 13 или получают 2d6 урона и опрокидывание"

Это:

- Вознаграждает творчество
- Создаёт memorable моменты
- Делает бой динамичным

### Когда сказать "Нет"

Скажи "Нет" если:

1. Действие ломает баланс игры
2. Противоречит установленным правилам мира
3. Отнимает момент у другого игрока
4. Игрок пытается "выиграть" D&D вместо того, чтобы играть

Пример плохой идеи:

- Игрок: "Я использую _Wish_, чтобы убить всех врагов в кампании"
- Мастер: "Нет. _Wish_ мощное, но не всемогущее. Ты можешь попытаться, но последствия будут катастрофическими"

## 4. Награды

### Опыт (XP)

Два подхода:

Подход 1: Расчётный XP

- Игроки получают XP за убитых врагов (сумма CR всех врагов)
- Таблица повышения уровня (см. PHB стр. 15)
- Плюсы: Прозрачно, математически точно
- Минусы: Много подсчётов, поощряет убийство вместо дипломатии

Подход 2: Milestone (Вехи) - РЕКОМЕНДУЕТСЯ

- Игроки повышают уровень после значимых событий
- Например:
    - Спасли деревню → 2 уровень
    - Убили первого босса → 3 уровень
    - Раскрыли заговор → 4 уровень
- Плюсы: Простота, фокус на истории, гибкость
- Минусы: Меньше ощущения "прогресса"

Комбинированный подход:

- Используй Milestones для основных уровней
- Давай бонусные XP за:
    - Хороший отыгрыш (+50-100 XP)
    - Решение головоломки (+100 XP)
    - Находчивость (+50 XP)

### Сокровища

Базовые рекомендации (DMG стр. 133):

|Уровень|Сокровище за столкновение|
|---|---|
|1-4|50-200 зм, редко магический предмет|
|5-10|500-2000 зм, иногда необычный магический предмет|
|11-16|2000-10000 зм, редкий магический предмет|
|17-20|10000+ зм, очень редкий/легендарный предмет|

Таблица сокровищ по CR (упрощённая):

|CR врага|Монеты|Шанс предмета|
|---|---|---|
|0-4|2d6 × 10 зм|10% (обычный)|
|5-10|2d6 × 100 зм|25% (необычный)|
|11-16|2d6 × 1000 зм|50% (редкий)|
|17+|2d6 × 10000 зм|75% (очень редкий)|

Не только золото:

- Драгоценности (изумруд 500 зм, рубин 1000 зм)
- Предметы искусства (картина, статуэтка)
- Карты, письма (зацепки для сюжета)
- Необычные предметы (магический, но не боевой: _Кувшин бесконечного эля_)

### Магические предметы

Редкость и уровни:

|Редкость|Рекомендуемый уровень|Примеры|
|---|---|---|
|Обычный|1+|_Зелье лечения_, _Факел вечного пламени_|
|Необычный|1-4|_+1 оружие_, _Плащ защиты_, _Сумка хранения_|
|Редкий|5-10|_+2 оружие_, _Кольцо защиты разума_, _Сапоги скорости_|
|Очень редкий|11-16|_+3 оружие_, _Амулет здоровья_ (ТЕЛ=19), _Ковёр-самолёт_|
|Легендарный|17+|_Святой мститель_, _Посох магов_, _Сфера уничтожения_|
|Артефакт|20|_Око Векны_, _Книга мерзкой тьмы_|

Как выдавать:

- 1-4 уровень: 1-2 необычных предмета на всю партию
- 5-10 уровень: +1 оружие/броня, пара необычных, 1 редкий
- 11-16 уровень: +2 оружие/броня, несколько редких, 1-2 очень редких
- 17-20 уровень: +3 оружие/броня, очень редкие, возможно легендарный

Баланс:

- Магические предметы НЕ обязательны в 5e (игра сбалансирована без них)
- Но они делают игру веселее
- Не давай слишком много - теряется ценность

### Альтернативные награды

1. Благословения (Blessings)

- Божество даёт постоянный бафф
- Пример: _Благословение здоровья_ (+2 максимум хитов за уровень)

2. Титулы и репутация

- "Герой Ивовой Лощины" - бесплатная еда/ночлег в деревне
- "Враг Культа Дракона" - культисты атакуют при встрече

3. Союзники и последователи

- NPC присоединяется к партии (но не в бою - работает как помощник)

4. Базы

- Игроки получают таверну, башню, корабль
- Источник дохода + место для отдыха

5. Информация

- Карта подземелья
- Слабость босса
- Секретный проход

## 5. Софт-скиллы Мастера

### Управление столом

Правило 1: Spotlight (прожектор)

- Каждый игрок должен получить момент в центре внимания
- Если кто-то молчит 20 минут - обратись к нему:
    - "Сэлин, что думает твой эльф об этом?"
    - "Торг, ты замечаешь что-то странное?"

Правило 2: Темп

- Не затягивай сцены без цели
- Если игроки 10 минут обсуждают, открывать ли дверь - "Так, вы открываете или нет?"
- Используй таймер для напряжённых ситуаций: "У вас 2 минуты реального времени решить, что делаете"

Правило 3: Session Zero (сессия 0)

- Перед началом кампании обсудите:
    - Тон игры (серьёзная/комедийная/ужасы)
    - Запретные темы (секс, пытки, расизм)
    - Частота игр
    - Ожидания (тактический бой vs RP vs исследование)

Правило 4: Lines and Veils

- Lines = Абсолютный запрет ("Никаких пыток детей")
- Veils = Можно упомянуть, но не детализировать ("Пытки происходят за кадром")

### Голос и атмосфера

1. Голоса для NPC

- Не обязательно быть актёром
- Достаточно менять:
    - Высоту голоса (низко/высоко)
    - Скорость речи (быстро/медленно)
    - Акцент (хоть слегка)
        
- Пример:
    - Старый мудрец: медленно, низко, с паузами
    - Нервный алхимик: быстро, высоко, запинается
    - Грубый кузнец: громко, отрывисто

2. Описания

- Используй 5 чувств:
    - Зрение: "Комната освещена тусклыми факелами, стены влажные"
    - Слух: "Слышишь капли воды и отдалённый вой"
    - Запах: "Пахнет гнилью и серой"
    - Осязание: "Воздух холодный и влажный"
    - Вкус: "Привкус металла во рту от страха"

3. Музыка и звуки

- Фоновая музыка для разных сцен:
    - Таверна: лёгкая, весёлая
    - Бой: эпичная, быстрая
    - Напряжение: тревожная, медленная
        
- Ресурсы:
    - [Tabletopaudio.com](https://tabletopaudio.com/)
    - [Syrinscape](https://syrinscape.com/)
    - YouTube: "D&D ambience"

### Импровизация историй

Техника 1: "Да, и..."

- Игрок: "Может, я знаю этого NPC из прошлого?"
- ❌ Плохо: "Нет, ты его не знаешь"
- ✅ Хорошо: "Да, и он должен тебе денег за старую услугу!"
    
Техника 2: Используй то, что игроки дают

- Игрок шутит: "Наверное, в сундуке мимик"
- Мастер: _записывает_ → В следующем сундуке действительно мимик
    

Техника 3: Списки имён

- Заготовь 10-15 имён для импровизированных NPC
- Мужские: Торн, Гаррет, Элдрик, Коран, Бран
- Женские: Лира, Селена, Миранда, Элара, Тиа

Техника 4: Модульные квесты

- Заготовь 2-3 побочных квеста, которые можно вставить где угодно:
    - "Пропала кошка"
    - "Нужно доставить письмо"
    - "Бандиты грабят караван"

### Работа с проблемными игроками

Тип 1: Отшельник (молчит всю сессию)

- Решение:
    - Обращайся напрямую: "Кейлан, что думает твой персонаж?"
    - Дай личный квест, где он главный
    - Поговори после сессии: может, стесняется или не нравится тон игры

Тип 2: Спотлайт-вор (доминирует всё время)
- Решение:
    - "Отличная идея, Джон! А что думают остальные?"
    - Дай другим игрокам моменты славы
    - Поговори наедине: "Дай другим тоже проявиться"

Тип 3: Rules Lawyer (спорит по каждому правилу)
- Решение:
    - "Понял, но сейчас решаем так. Обсудим после сессии"
    - Признавай, когда прав: "Ты прав, спасибо!"
    - Делегируй: "Можешь быть мне помощником по правилам?"

Тип 4: Chaotic Stupid (рушит сюжет ради хаоса)
- Решение:
    - Последствия: убил NPC - стража его ищет
    - Разговор: "Это мешает остальным получать удовольствие"
    - В крайнем случае: исключи из группы

## 7. Подготовка к сессии

### За неделю до игры

-  Определи основную сюжетную нить сессии
-  Подготовь 2-3 ключевых сцены
-  Заготовь 3-4 случайных встречи (на случай импровизации)
-  Подготовь характеристики врагов
-  Запиши имена NPC

### За день до игры

-  Перечитай заметки прошлой сессии
-  Подготовь карты (если используешь)
-  Скачай музыку/эмбиенты
-  Распечатай стат-блоки монстров
-  Подготовь сокровища/награды

### За час до игры

-  Настрой Foundry VTT (загрузи карты, токены, музыку)
-  Открой все нужные вкладки/PDF
-  Проверь связь с игроками
-  Подготовь напитки/закуски (если живая игра)

## 8. Структура сессии (3-4 часа)

0:00-0:15 - Разогрев
- Светская беседа
- Краткий recap прошлой сессии
- "Когда мы закончили, вы стояли перед воротами..."

0:15-1:00 - Исследование/RP
- Город, общение с NPC, сбор информации
- Дай каждому игроку момент проявить себя

1:00-1:15 - Перерыв

1:15-2:30 - Экшн (бой/погоня/напряжённая сцена)
- Центральное столкновение сессии
- Или: сложная головоломка, драматическая сцена

2:30-3:00 - Развязка и хук
- Награды, разговоры с NPC
- Cliffhanger на следующую сессию

## 9. Сторителлинг

### Структура истории (классическая)

Акт 1: Введение (25%)
- Знакомство с миром
- Встреча с ключевым NPC
- Завязка (Inciting Incident): событие, запускающее приключение
    
Акт 2: Развитие (50%)

- Исследование, раскрытие тайн
- Побочные квесты 
- Мидпойнт: крупное открытие, меняющее всё
- Усиление напряжения

Акт 3: Кульминация (25%)

- Финальная битва
- Разрешение конфликта
- Развязка: последствия, награды, новые зацепки

Пример (ваншот "Тайна Ивовой Лощины"):

- Акт 1: Прибытие, знакомство с деревней, встреча с Мартой → Завязка: Торин мёртв, Элара пропала
- Акт 2: Расследование (дом, алхимик, церковь) → Мидпойнт: Находка книги и понимание, что вызван дух
- Акт 3: Кладбище, битва с Wraith, спасение Элары → Развязка: Судьба Кейлена, награды
    
### Техники повествования

1. Show, Don't Tell

- ❌ Плохо: "Вы видите мёртвое тело. Оно выглядит страшно"
- ✅ Хорошо: "Торин лежит на кровати, глаза широко открыты, лицо искажено в безмолвном крике. Кожа бледная, почти синеватая, и когда ты касаешься его руки - она ледяная, как мрамор"

2. Foreshadowing (предзнаменование)

- Дай подсказки заранее
- Пример: В таверне упоминают "странные звуки с кладбища" → позже там будет бой
- Игроки почувствуют себя умными, когда соединят точки

3. Chekhov's Gun

- Если упомянул деталь - используй её
- Если на стене висит ружьё (упомянул) → кто-то должен выстрелить из него

4. Cliffhanger

- Заканчивай сессии на напряжённом моменте:
    - "Вы открываете дверь склепа... и видите, как Элара медленно поворачивает к вам голову. Её глаза светятся зелёным. До встречи на следующей неделе!"

5. Персональные хуки

- Свяжи сюжет с предысторией персонажей
- Если у игрока в бэкграунде "погибший брат" → сделай, чтобы злодей был как-то связан с этим
    
### Создание запоминающихся NPC

Формула:

`Простая цель + Странная черта + Секрет = Интересный NPC`

Пример:

- Цель: Найти пропавшую дочь (Бран Молот)
- Странная черта: Всегда стучит молотом по наковальне, даже когда нервничает
- Секрет: Знает, что дочь встречалась с Кейленом, но не хочет признавать, что был слишком строг

Другой пример:
- Цель: Скрыть свою вину (Кейлен)
- Странная черта: Постоянно протирает очки
- Секрет: Влюблён в Элару и вызвал духа случайно

## Темп и напряжение

Чередуй интенсивность:

- Бой → Разговор → Исследование → Бой
- НЕ делай 3 боя подряд (усталость)
- НЕ делай 2 часа только разговоров (скука)
    
Таймеры и дедлайны:

- "У вас есть 3 дня до полнолуния, когда ритуал завершится"
- Это создаёт urgency (срочность)

## Итоговый чек-лист Мастера

### Перед кампанией
 
- Session Zero проведена
-  Мир и тон определены
-  Запретные темы оговорены
-  У каждого игрока есть персональный хук

### Перед каждой сессией

-  Ключевые сцены подготовлены
-  NPC с целями/секретами готовы
-  Стат-блоки врагов под рукой
-  Карты/токены/музыка загружены
-  Cliffhanger прошлой сессии помню

### Во время сессии

-  Каждый игрок получил spotlight
-  Темп держу (не затягиваю)
-  Импровизирую с "Да, и..."
-  Записываю важные моменты
    

### После сессии

-  Записал, что произошло
-  Отметил незакрытые квесты
-  Подготовил хук на следующую сессию
-  Попросил фидбек у игроков (раз в месяц)

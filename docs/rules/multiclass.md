# Мультиклассирование в D&D 5e

## Что такое мультиклассирование?

Мультиклассирование (Multiclassing) - это возможность брать уровни в нескольких классах одновременно, создавая уникальные комбинации способностей.

Пример:  
Воин 5 / Плут 3 - персонаж с 5 уровнями воина и 3 уровнями плута (общий уровень 8).

:::caution Важно
Мультиклассирование - опциональное правило. Спроси у мастера, разрешено ли оно в вашей игре.
:::

---

## 📋 Требования

Чтобы взять уровень в новом классе, нужно иметь минимум 13 в определённой характеристике:

| Класс | Требование |
|-------|-----------|
| Варвар | СИЛ 13 |
| Бард | ХАР 13 |
| Воин | СИЛ 13 или ЛОВ 13 |
| Волшебник | ИНТ 13 |
| Друид | МДР 13 |
| Жрец | МДР 13 |
| Колдун | ХАР 13 |
| Монах | ЛОВ 13 и МДР 13 |
| Паладин | СИЛ 13 и ХАР 13 |
| Плут | ЛОВ 13 |
| Следопыт | ЛОВ 13 и МДР 13 |
| Чародей | ХАР 13 |

Важно: Требование проверяется при взятии нового класса, не при повышении уже взятого.

## 🎯 Как работает?

### Уровни и опыт

- Общий уровень = сумма уровней всех классов
- Опыт считается по общему уровню
- Бонус мастерства зависит от общего уровня

Пример:  
Воин 3 / Волшебник 2 = 5 уровень (бонус мастерства +3)

### Хиты

При взятии нового класса:

- Бросаешь (или берёшь среднее) кость хитов нового класса
- Добавляешь модификатор ТЕЛ

Пример:  
Волшебник 1 (6 хитов) берёт уровень Воина:
- Бросает 1d10 (или берёт 6) + модификатор ТЕЛ
- Если d10 = 8 и ТЕЛ +2, то +10 хитов

### Владения

При мультиклассе НЕ получаешь все владения нового класса!

Получаешь только:

- Лёгкие владения (часть оружия/брони)
- Спасброски - НЕТ
- Навыки - ограниченный выбор

Таблица владений при мультиклассе:

| Класс | Получаешь |
|-------|-----------|
| Варвар | Щиты, простое оружие, воинское оружие |
| Бард | Лёгкая броня, 1 навык, 1 музыкальный инструмент |
| Воин | Лёгкая/средняя броня, щиты, простое/воинское оружие |
| Волшебник | - |
| Друид | Лёгкая/средняя броня, щиты |
| Жрец | Лёгкая/средняя броня, щиты |
| Колдун | Лёгкая броня, простое оружие |
| Монах | Простое оружие, короткие мечи |
| Паладин | Лёгкая/средняя броня, щиты, простое/воинское оружие |
| Плут | Лёгкая броня, 1 навык |
| Следопыт | Лёгкая/средняя броня, щиты, простое/воинское оружие, 1 навык |
| Чародей | - |

## 🔮 Заклинания при мультиклассе

### Ячейки заклинаний

Формула расчёта:

1. Суммируй уровни полных заклинателей (Бард, Волшебник, Друид, Жрец, Чародей)
2. Суммируй уровни полузаклинателей (Паладин, Следопыт), раздели на 2 (округление вниз)
3. Суммируй уровни третьезаклинателей (Воин Eldritch Knight, Плут Arcane Trickster), раздели на 3 (округление вниз)
4. Итого = общий уровень заклинателя для определения ячеек

Пример 1:  
Волшебник 3 / Воин 4 = 3 (полный заклинатель) = 3 уровень заклинателя  
Ячейки: как у заклинателя 3 уровня (4 ячейки 1 уровня, 2 ячейки 2 уровня)

Пример 2:  
Паладин 4 / Колдун 3 = 2 (полузаклинатель: 4÷2) + 3 (полный) = 5 уровень заклинателя  
Ячейки: как у заклинателя 5 уровня

### Известные/подготовленные заклинания

Важно: Заклинания считаются отдельно для каждого класса!

- Волшебник 3 / Жрец 2 может готовить заклинания волшебника 3 уровня и жреца 2 уровня
- Но ячейки общие (по формуле выше)

Ограничение: Можно знать/готовить заклинания только того уровня, к которому есть доступ в конкретном классе.

Пример:  
Волшебник 3 / Жрец 2 (общий заклинатель 5 уровня, есть ячейки 3 уровня):
- ✅ Может использовать ячейку 3 уровня для _Fireball_ (заклинание волшебника 3 уровня)
- ❌ НЕ может выучить _Revivify_ (заклинание жреца 3 уровня) - у него только 2 уровня жреца

## 💎 Популярные комбинации

### 1. Паладин / Колдун

Синергия:

- Паладин: Divine Smite (использует ячейки)
- Колдун: Ячейки восстанавливаются на коротком отдыхе

Комбо: Короткие отдыхи дают бесконечные Smite'ы!

Рекомендуемый сплит: Паладин 6 / Колдун X или Паладин 2 / Колдун X

### 2. Воин / Плут

Синергия:

- Воин: Дополнительные атаки, Action Surge
- Плут: Sneak Attack (огромный урон)

Комбо: Action Surge позволяет сделать ещё один Sneak Attack в том же раунде!

Рекомендуемый сплит: Воин 5 / Плут X (для Extra Attack)

### 3. Друид / Монах

Синергия:

- Друид: Wild Shape (превращение в зверей)
- Монах: Martial Arts, Unarmored Defense

Комбо: В форме зверя можешь использовать Martial Arts!

Рекомендуемый сплит: Друид 2-3 / Монах X

### 4. Bард / Паладин

Синергия:

- Бард: Charisma-based, поддержка
- Паладин: Divine Smite, аура защиты

Комбо: Харизматичный лидер с божественной силой.

Рекомендуемый сплит: Паладин 6 / Бард X

### 5. Warlock / Sorcerer (Sorlock)

Синергия:

- Колдун: _Eldritch Blast_ + Agonizing Blast
- Чародей: Quickened Spell (метамагия)

Комбо: 2× Eldritch Blast за раунд (Action + Bonus Action)!

Рекомендуемый сплит: Колдун 2-3 / Чародей X

## ⚠️ Когда НЕ стоит мультиклассировать?

### 1. Ты новичок

Мультикласс усложняет игру. Сначала освой один класс.

### 2. Теряешь capstone (20 уровень класса)

Capstone способности (20 уровень) очень мощные!

Примеры:

- Варвар: +4 СИЛ/ТЕЛ (максимум 24)
- Друид: Бесконечный Wild Shape
- Паладин: +10 к спасброскам для всех союзников

Если играешь до 20 уровня - подумай дважды.

### 3. Замедляешь прогресс основного класса

Пример:  
Волшебник 17 / Воин 3 не получает заклинания 9 уровня (_Wish_, _Meteor Swarm_).

### 4. Характеристики не подходят

Если у тебя СИЛ 10, а ты хочешь взять Воина - это плохая идея.

## 💡 Советы по мультиклассированию

### 1. Планируй заранее

Знай, когда и зачем берёшь уровни другого класса.

### 2. Синергия > механики

Мультикласс должен иметь смысл для персонажа, не только механически.

Плохо: "Я беру Колдуна ради Eldritch Blast, хотя мой персонаж ненавидит магию."

Хорошо: "Мой паладин заключил сделку с существом, чтобы спасти товарища - теперь он колдун."

### 3. Избегай MAD (Multiple Ability Dependency)

MAD = зависимость от множества характеристик.

Плохо: Монах (ЛОВ + МДР) / Паладин (СИЛ + ХАР) - нужно 4 характеристики!

Хорошо: Паладин (СИЛ + ХАР) / Колдун (ХАР) - обе используют ХАР.

### 4. Не затягивай key способности

Key способности - важные фичи класса (Extra Attack, Fireball, Sneak Attack 3d6+).

Берите мультикласс после получения ключевых способностей (обычно 5 уровень).

## ❓ Частые вопросы

Q: Могу ли я брать больше 2 классов?  
A: Да, но это очень сложно и редко имеет смысл.

Q: Если у меня Воин 4 / Плут 4, когда я получу ASI?  
A: ASI даётся классом, не общим уровнем. Ты получил ASI на Воине 4 и получишь на Плуте 4 (или возьмёшь feat).

Q: Колдун особенный?  
A: Да! Ячейки Колдуна отдельные и восстанавливаются на коротком отдыхе. Они не суммируются с обычными.

Q: Можно ли мультиклассировать одинаковыми подклассами?  
A: Нет, не можешь взять "Воин (Champion) / Воин (Battle Master)". Это один класс.

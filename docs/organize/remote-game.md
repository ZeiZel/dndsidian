# Организация удалённой игры

## Введение

Удалённая игра в D&D открывает возможность играть с людьми из любой точки мира. Современные технологии делают онлайн-игру почти такой же увлекательной, как и вживую.

---

## Варианты удалённой игры

### 1. Text-Based (Текстовая игра)

Платформы:

- Discord (текстовые каналы)
- Telegram
- Forum-based (Play-by-Post)

Как это работает:

```
🎭 Мастер: Вы входите в тёмную таверну. 
За барной стойкой стоит суровый дворф.

🎲 Игрок 1: Я подхожу к барману. 
"Добрый вечер! Не видели ли вы здесь эльфийку?"
[Persuasion: !roll 1d20+3 = 18]

🤖 Бот: @Игрок1 выбросил 18 (Убеждение)

🎭 Мастер: Дворф хмыкает и указывает на дальний стол...
```

Преимущества:

- ✅ Можно играть асинхронно (не обязательно все онлайн одновременно)
- ✅ Идеально для застенчивых игроков
- ✅ Запись всей игры автоматически
- ✅ Можно писать длинные описания и отыгрыш
- ✅ Не нужен микрофон/камера

Недостатки:

- ❌ Медленнее - бой может тянуться часами
- ❌ Меньше эмоций - не слышишь голоса
- ❌ Сложнее импровизировать

Когда использовать:

- Группа в разных часовых поясах
- Игроки стесняются говорить голосом
- Play-by-Post кампании (медленный темп)

Боты для Discord:

- Avrae - полный набор инструментов D&D
- Dice Maiden - броски кубиков
- Sidekick - управление персонажами

---

### 2. Voice-Only (Только голос)

Платформы:

- Discord (голосовые каналы)
- Zoom (без видео)
- Teamspeak
- Skype

Преимущества:

- ✅ Быстрее текстовой игры
- ✅ Слышишь эмоции и интонации
- ✅ Меньше нагрузка на интернет (чем с видео)
- ✅ Можно играть в пижаме 😄

Недостатки:

- ❌ Не видишь язык тела
- ❌ Сложнее понять, кто говорит (если много игроков)
- ❌ Меньше погружения

Настройки для качества:

Микрофон:

- Используй наушники (чтобы не было эха)
- Push-to-Talk (чтобы не было фонового шума)
- Проверь уровень громкости (не слишком тихо/громко)

Discord настройки:

- Voice Activity (автоматическое определение голоса)
- Noise Suppression (подавление шума)
- Echo Cancellation (убрать эхо)

---

### 3. Video + VTT (Видео + Виртуальный стол)

Полноценный опыт - видео + карты + автоматизация.

Платформы:

- Foundry VTT (самый мощный, $50 единоразово)
- Roll20 (бесплатный, браузерный)
- D&D Beyond (официальный, интеграция с Roll20)
- Fantasy Grounds (платный, мощный)
- Owlbear Rodeo (минималистичный, бесплатный)

Сравнительная таблица:

| Платформа | Цена | Сложность | Возможности | Рекомендация |
|-----------|------|-----------|-------------|--------------|
| Roll20 | Бесплатно (есть подписка) | Низкая | Средние | Новичкам |
| Foundry VTT | $50 (навсегда) | Средняя | Высокие | Опытным/техническим |
| D&D Beyond | Подписка ($6-30/мес) | Низкая | Средние | Любителям официального контента |
| Fantasy Grounds | $10/мес или $150 навсегда | Высокая | Высокие | Хардкорным мастерам |
| Owlbear Rodeo | Бесплатно | Очень низкая | Базовые | Минималистам |

## Подробная настройка Foundry VTT (с удалённым доступом)

Foundry VTT - мощная платформа, которая работает локально на твоём компьютере. Чтобы дать доступ игрокам через интернет, нужна дополнительная настройка.

### Архитектура решения

Используем WireGuard туннель через Pangolin для безопасного соединения:

```
[Игроки из интернета] 
    ↓ HTTPS
[Удалённый VPS: Caddy :443] 
    ↓ HTTP через туннель
[Удалённый VPS: Pangolin Server] 
    ↓ WireGuard туннель через интернет
[Локальная машина: Pangolin Client] 
    ↓ Локальная сеть
[Локальная машина: Foundry VTT :30000]
```

Преимущества:

- ✅ Foundry работает локально (все данные на твоём ПК)
- ✅ Доступ через удалённый домен с SSL
- ✅ Безопасное соединение

### Пошаговая настройка

:::info Полная инструкция
Детальная инструкция по настройке удалённого сервера, Pangolin туннеля, Caddy и Docker находится в папке `remote-game/`. 

Там вы найдёте:
- Скрипты установки зависимостей
- Docker Compose конфигурации
- Caddyfile примеры
- Troubleshooting

:::

Краткий обзор шагов:

1. Арендуй VPS (например, на [Timeweb](https://timeweb.com))
2. Купи домен и настрой A-запись на IP сервера
3. Установи зависимости на сервер (Ansible, Docker, Caddy)
4. Настрой Pangolin (WireGuard туннель)
5. Запусти Foundry локально
6. Настрой Caddy для reverse proxy
7. Подключи игроков через твой домен (например, `foundry.yourdomain.ru`)

➡️ [Детальная инструкция в папке remote-game/](/docs/organize/remote-game/howto#удалённая-игра)

## Гибридный формат

Часть игроков за столом, часть онлайн - возможно, но требует подготовки.

Что нужно:

- 🎤 Качественный микрофон на столе (чтобы онлайн-игроки слышали всех)
- 📹 Камера на карту/миниатюры (чтобы онлайн-игроки видели поле боя)
- 🔊 Колонка для воспроизведения голосов онлайн-игроков

Настройка:

```
[Стол с игроками]
    ↓
[Микрофон] → [Компьютер] → [Discord/Zoom]
[Камера] ↗                      ↓
                         [Онлайн-игроки]
```

Советы:

- Мастер повторяет вслух, что говорят онлайн-игроки
- Онлайн-игроки сигналят, когда хотят сказать (например, реакция в Discord)
- Используй Discord для голоса + Foundry для карты (оба видят карту)

## Советы для удалённой игры

### 1. Техническая подготовка

До первой сессии:

- [ ] Проверь микрофон и камеру
- [ ] Протестируй платформу (VTT)
- [ ] Убедись, что интернет стабилен
- [ ] Закрой лишние программы (чтобы не тормозило)

### 2. Коммуникация

Правила общения:

- 🎙️ Mute когда не говоришь (если нет Push-to-Talk)
- 🙋 Сигнализируй, когда хочешь сказать (поднять руку в Zoom)
- 💬 Используй текстовый чат для быстрых заметок/ссылок
- ⏱️ Не затягивай свой ход (думай заранее)

### 3. Атмосфера

Даже онлайн можно создать настроение:

- 🎵 Музыка - включи фоновую через Discord бота или поделись аудио
- 🖼️ Арты - показывай картинки локаций/NPC
- 🎭 Голоса - используй разные интонации для NPC
- 🕯️ Свечи у себя - создай атмосферу лично

### 4. Перерывы

Важно делать перерывы:

- После 1-1.5 часов
- 10-15 минут на туалет/разминку/закуски
- Используй таймер (чтобы не затянуть)

## Troubleshooting

### Проблема: Лагает

Решения:

- Закрой лишние вкладки/программы
- Понизь качество видео
- Отключи видео (оставь только голос)
- Перезагрузи роутер

### Проблема: Микрофон шумит

Решения:

- Включи Noise Suppression в Discord
- Используй наушники (убрать эхо)
- Отодвинься от источников шума
- Используй Push-to-Talk

### Проблема: Кто-то не может подключиться к Foundry

Решения:

- Проверь, работает ли интернет у него
- Убедись, что он использует правильную ссылку
- Проверь, запущен ли Foundry у тебя
- Проверь firewall/антивирус

### Проблема: VTT тормозит

Решения:

- Уменьши размер карт (оптимизируй изображения)
- Отключи ненужные модули (Foundry)
- Закрой лишние вкладки браузера
- Используй менее детальные токены

## Преимущества удалённой игры

- 🌍 География - играй с кем угодно, где угодно
- 🤖 Автоматизация - VTT считает модификаторы автоматически
- 📚 Ресурсы - быстрый доступ к PDF, справочникам
- 💾 Запись - можно записывать сессии
- 💰 Экономия - не нужно ехать, покупать физические материалы

---

## Недостатки удалённой игры

- 🔌 Зависимость от интернета
- 🤝 Меньше личного контакта
- 🖥️ Технические проблемы
- 😴 Легче отвлечься (соцсети, игры)

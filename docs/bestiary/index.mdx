# Бестиарий D&D 5e

Бестиарий содержит описания монстров и существ для ваших приключений. Каждое существо имеет уровень опасности (КО), определяющий его силу.

## Уровни опасности (КО)

| КО | Опыт | Рекомендуемая группа |
|----|------|----------------------|
| 0 | 0-10 | Тренировочный бой |
| 1/8-1/4 | 25-50 | 1-й уровень, несколько |
| 1/2-1 | 100-200 | 1-2 уровень |
| 2-4 | 450-1100 | 3-5 уровень |
| 5-10 | 1800-5900 | 6-10 уровень |
| 11-16 | 7200-15000 | 11-16 уровень |
| 17+ | 18000+ | 17+ уровень |

## Использование бестиария

### Для мастера

1. **Выбор противников:** Подбирайте монстров по КО для баланса
2. **Разнообразие:** Комбинируйте разные типы для интереса
3. **Тактика:** Изучайте способности для интересных боёв
4. **Модификация:** Изменяйте существ под свою историю

### Расчёт сложности

Используйте XP для расчёта:
1. Сложите XP всех монстров
2. Умножьте на модификатор группы
3. Сравните с порогами сложности группы

| Количество монстров | Множитель |
|--------------------|-----------|
| 1 | ×1 |
| 2 | ×1.5 |
| 3-6 | ×2 |
| 7-10 | ×2.5 |
| 11-14 | ×3 |
| 15+ | ×4 |
